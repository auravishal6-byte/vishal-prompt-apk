Vishal's Prompting Principles

The 4 core rules for deterministic, accurate AI output

01

Specify Output Schema

Never let the model guess layout. Dictate headings, bullet formatting, or JSON schema upfront.

02

Provide Negative Constraints

Explicitly state what NOT to do (e.g., "Do not include conversational filler or introduction").

03

Chain-of-Thought Enforcement

Ask the model to explain its reasoning step-by-step before delivering final conclusions.

04

Set Strict Grounding Rules

Instruct the model to cite confidence levels and explicitly state when data is unavailable.
